작전의 시간 개인정보처리방침

앱: 작전의 시간 (Android)
개발자 표시명: Diverse.Studio
시행일: 2026-10-27

1. 적용 범위와 앱의 처리

작전의 시간은 AI 구단과 겨루는 오프라인 전략 게임입니다. 회원가입, 로그인, 온라인 대전, 개발자 서버 및 클라우드 저장을 제공하지 않습니다. 앱에서 게임 정보나 이용자의 정보를 개발자 또는 제3자에게 전송·수집·공유하지 않습니다.

광고, 앱 내 구매, 분석·추적 및 원격 오류 수집 서비스를 연동하지 않았으며 해당 SDK도 사용하지 않습니다. 인터넷 권한을 요청하지 않습니다. 연락처·위치·카메라·마이크 등 게임에 필요하지 않은 개인정보 접근 권한도 요청하지 않습니다.

2. 기기에 저장하는 정보와 목적

게임을 이어 하고 진행을 복구하기 위해 구단·선수단, 사용자가 정한 선수 이름, 선수 성장·경기 기록, 시즌·시리즈 진행, 게임 내 재화와 설정 등을 앱 전용 기기 저장공간에 저장합니다. 저장 실패나 형식 변경에 대비한 로컬 복구용 사본도 같은 기기에 남을 수 있습니다. 선수 이름에 실명이나 연락처를 입력할 필요가 없습니다.

이 정보는 기기 안에서만 사용하며 개발자가 원격으로 열람하지 않습니다. Android 자동 앱 백업을 사용하지 않고, 기기 간 동기화나 개발자 서버 복구도 제공하지 않습니다.

3. 보관과 로컬 정보 삭제

로컬 정보는 앱의 저장공간에 보관됩니다. Android의 설정 → 앱 → 작전의 시간 → 저장공간 → 데이터 삭제 또는 앱 제거로 게임 저장과 로컬 복구용 사본을 삭제할 수 있습니다. 기기에 따라 메뉴 이름은 다릅니다. 이 작업으로 진행을 잃게 되며 개발자가 복구할 수 없습니다.

개발자 서버 계정이 없으므로 서버 계정 삭제 절차는 없습니다. 앱 삭제는 별도로 보낸 지원 이메일까지 삭제하지 않습니다.

4. 자발적으로 보낸 지원 이메일

이용자가 문의를 보내면 발신 이메일 주소, 표시 이름, 문의 내용과 직접 첨부한 자료를 받습니다. 답변, 문제 확인과 문의 이력 관리에 필요한 범위에서 처리하며 광고나 이용자 추적에 사용하거나 공개 게시하지 않습니다. 문의하지 않아도 게임을 이용할 수 있습니다.

문의 처리에 필요한 담당자만 정보를 확인하도록 관리합니다. 비밀번호·신분증·금융정보나 불필요한 개인정보를 보내지 마세요. 이메일과 별도로 저장한 사본은 문의 해결 후 더 이상 필요하지 않으면 검토해 삭제하며, 법령에 따른 보관 의무가 있으면 해당 범위에서 보관합니다. 자동 삭제나 즉시 완전 소거를 약속하지 않습니다.

지원 메일은 Gmail을 사용합니다. Google의 이메일 전송·보관 처리는 Google 개인정보처리방침을 따릅니다. 이는 앱이 게임 정보를 외부로 전송한다는 의미가 아닙니다.

5. 이 지원 웹사이트

이 정적 지원 페이지에는 자체 광고·분석·추적 스크립트, 문의 양식, 로그인 또는 자체 쿠키를 넣지 않습니다. 이메일 링크는 이용자의 메일 앱을 엽니다.

웹사이트는 GitHub Pages를 이용합니다. GitHub는 방문자의 로그인 여부와 관계없이 보안 목적으로 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub Pages의 정보 수집 안내와 GitHub 개인정보처리방침을 확인해 주세요. Google 및 GitHub는 이용자 거주 국가 외 지역에서 정보를 처리할 수 있으며 각 제공자의 정책과 적용 법령이 적용됩니다.

6. 선택과 권리 행사

기기 정보는 이용자가 Android 저장공간 설정에서 직접 삭제할 수 있습니다. 개발자가 보유한 문의 정보의 열람·정정·삭제 등 요청은 아래 이메일로 보내실 수 있습니다. 실제 보유 범위와 적용 법령에 따라 처리하며, 개발자가 접근할 수 없는 기기 로컬 정보는 원격으로 열람·삭제할 수 없습니다.

7. 이용 대상과 변경 안내

13세 이상 청소년과 성인을 의도한 게임이며, 13세 미만 어린이를 주된 대상으로 기획하지 않았습니다. 앱에는 생년월일 수집이나 나이 확인 기능이 없습니다. 이는 국가별 개인정보 동의 연령이나 Google Play 콘텐츠 등급을 확정하는 설명은 아닙니다.

게임 기능이나 정보 처리 방식이 달라지면 이 방침과 시행일을 변경하고 필요한 안내 및 법령상 요구되는 절차를 제공합니다.
