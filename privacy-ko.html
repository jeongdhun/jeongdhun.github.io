1. 현재 제공하는 기능

굴착볼은 광석을 채굴하는 게임입니다. 무료 플레이에 로그인이나 온라인 연결을 요구하지 않으며 진행은 기기에 저장됩니다. 현재 개발 버전의 광고는 Google 공식 테스트 광고입니다.

로그인·서버 계정·클라우드 저장·유료 상품 판매·서버 구매 검증·공개 광고 보상 검증 서버는 현재 운영하지 않습니다. 관련 코드나 라이브러리가 포함돼 있어도 운영 중인 서비스로 취급하지 않습니다. 해당 서비스를 시작하기 전에 실제 처리 내용에 맞춰 이 방침을 변경하고 필요한 안내를 제공합니다.

2. 기기에 저장하는 정보

단계 진행, 코인, 채굴 기록, 개량, 설정, 이어하기 상태, 보상·도구의 중복 처리를 막는 기록 및 기술 진단 기록을 기기에 저장합니다. Diverse.Studio의 운영 서버로 진행 정보를 전송하는 기능은 활성화돼 있지 않습니다. 별도 자체 분석 또는 오류 수집 서비스를 연결하지 않았습니다. 이는 Google SDK의 정보 처리가 없다는 뜻은 아닙니다.

현재 앱은 Android 자동 앱 백업을 사용하지 않습니다. 앱 데이터 삭제나 앱 제거 시 로컬 진행을 잃을 수 있으며 개발자 서버에서 복구할 수 없습니다.

3. Google 광고 SDK와 개인정보 선택

Google Mobile Ads SDK는 IP 주소, 광고·앱 식별자, 앱·광고 상호작용 및 진단 정보를 광고 제공·측정·부정행위 방지 등에 처리할 수 있습니다. IP 주소로 대략적인 위치가 추정될 수 있으며 전송은 암호화됩니다. 테스트 광고도 Google과 통신할 수 있습니다.

앱은 Google User Messaging Platform(UMP)을 통해 동의 정보를 갱신하고, SDK가 광고 요청을 허용하는 경우에만 광고를 요청합니다. SDK가 개인정보 옵션을 요구하면 앱 설정에서 해당 양식을 열 수 있습니다. 지역과 동의 메시지 구성에 따라 선택 내용이 다릅니다. 운영 앱의 유럽 동의 메시지는 게시 준비 중이며 이미 게시됐다고 주장하지 않습니다.

Google의 처리는 Google 개인정보처리방침과 Google 서비스를 사용하는 앱의 정보 처리 안내를 확인하세요. Android 설정의 광고 개인정보 옵션도 이용할 수 있습니다. 동의 변경은 이미 확정된 게임 보상을 취소하지 않습니다.

4. Google Play 라이브러리

Google Play Billing 라이브러리가 포함돼 있으며 시작 시 Play에 연결해 상품 또는 보유 상태를 조회할 수 있습니다. 현재 실제 구매·코인팩 판매·개발자 계정 연결은 비활성 상태입니다. Diverse.Studio가 결제카드 정보를 입력받는 기능은 없습니다. Google Play의 처리는 Google의 정책을 따릅니다. QA 구매 시뮬레이션은 실제 결제가 아닙니다.

5. 문의 정보와 공개 웹페이지

지원 또는 개인정보 문의를 보내면 제공한 이메일 주소와 문의 내용이 담당자에게 전달됩니다. 문의 해결에 필요한 정보만 보내고 비밀번호, 전체 구매 토큰, 신분증, 결제카드 정보는 보내지 마세요.

문의 처리 목적을 달성하면 불필요한 개인정보를 담당자가 정리·삭제하고, 적용되는 보관 의무가 있으면 필요한 범위만 보관합니다. 수신·발신 이메일, 첨부파일과 별도로 저장한 사본을 담당자가 검토해 정리하는 방식이며 자동 삭제나 즉시 완전 소거를 약속하지 않습니다.

공개 이메일은 Gmail을 사용합니다. 메일 전송·보관 과정의 Google 처리는 Google 개인정보처리방침을 따르며, Diverse.Studio의 문의 처리와 구분됩니다. 이 페이지의 이메일 링크는 이용자의 메일 앱을 열며 웹페이지에서 문의를 수집하지 않습니다.

이 정적 웹페이지에는 자체 광고·분석·추적 스크립트, 로그인, 문의 양식 또는 자체 쿠키를 넣지 않습니다. 이 웹사이트는 무료 GitHub Pages로 호스팅합니다. GitHub Pages는 방문자의 로그인 여부와 관계없이 보안 목적으로 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보처리방침을 확인하세요. 호스팅 제공자의 접속 기록 처리와 앱 개발자의 로컬 게임 저장은 별개입니다.

6. 삭제·선택·문의

로컬 게임 정보는 Android 앱 설정에서 저장공간을 삭제하거나 앱을 제거하면 삭제할 수 있습니다. 이 작업은 진행을 지우므로 주의하세요. 현재 개발자 서버에 생성되는 사용자 계정은 없으며 별도 서버 계정 삭제 페이지도 운영하지 않습니다.

Google이 처리하는 정보와 광고 식별자의 관리에는 Google 개인정보 도구와 Android 광고 설정을 이용하세요. Diverse.Studio가 보유하는 문의 정보의 열람·정정·삭제 요청은 아래 연락처로 보낼 수 있으며 적용 법령과 실제 보유 범위에 따라 처리합니다. 기기 로컬 정보는 개발자가 원격으로 열람·삭제할 수 없습니다.

7. 이용 대상

굴착볼은 13세 이상 청소년과 성인을 의도한 일반 퍼즐 게임이며, 13세 미만 어린이를 주된 이용자로 기획한 서비스는 아닙니다. 이는 콘텐츠 등급이나 모든 국가의 개인정보 동의 연령을 확정하는 표현이 아닙니다. 현재 앱에는 생년월일을 수집하거나 이용자의 나이를 확인하는 화면이 없습니다. 연령별 광고 처리가 이미 구현됐다고 주장하지 않으며, 운영 광고 제공 전 대상 국가에 필요한 SDK·동의 설정을 별도로 검토합니다.

8. 처리 지역·방침 변경

Google 등 서비스 제공자는 거주 국가 외 지역에서 정보를 처리할 수 있으며 제공자의 정책과 적용 법령에 따릅니다. 운영하지 않는 개발자 서버의 소재지나 보관 기간은 지정하지 않습니다.

기능과 처리 방식이 바뀌면 이 페이지와 시행일을 변경하고 필요한 경우 앱에서도 안내와 동의 절차를 제공합니다.
