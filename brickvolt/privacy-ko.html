1. 현재 제공하는 게임

브릭볼트는 13세 이상 청소년과 성인을 대상으로 하는 캐주얼 벽돌 깨기 퍼즐입니다. 플레이에 개발자 계정이나 로그인을 요구하지 않으며 진행은 기기에 저장합니다. 현재 유료 상품 구매와 클라우드 저장은 제공하지 않습니다.

게임 플레이 화면에서는 이름, 이메일 주소, 생년월일 또는 로그인 정보를 입력받지 않습니다. 별도의 자체 분석 서비스를 운영하지 않습니다.

현재 비공개 테스트 버전에는 광고 SDK와 동의 SDK가 포함되지 않습니다. 게임 앱은 광고를 요청하거나 게임 진행을 기기 외부로 전송하지 않습니다.

2. 기기에 저장하는 진행 정보

스테이지 진행과 클리어 기록, 시작 공의 성장, 이어하기 상태, 무한 모드 기록, 소리와 꾸미기 선택 등을 기기에 저장합니다. 이 진행을 Diverse.Studio의 운영 서버에 업로드하는 기능은 제공하지 않습니다.

Android 앱 설정에서 저장공간을 지우거나 앱을 제거하면 로컬 진행을 잃을 수 있습니다. 개발자가 기기 진행을 원격으로 복구하거나 삭제하는 서비스는 없습니다. 기기 저장을 지워도 이미 보낸 문의 이메일이나 외부 웹사이트에서 처리하는 정보가 함께 삭제되지는 않습니다.

3. 외부 브라우저와 메일 링크

게임 설정의 개인정보처리방침과 고객 지원 링크를 선택하면 외부 브라우저에서 웹페이지가 열립니다. 이메일 링크는 이용자의 메일 앱을 엽니다. 웹페이지를 열거나 메일을 보내면 게임의 로컬 저장과 별도로 해당 외부 서비스에서 정보를 처리할 수 있습니다.

4. 지원 이메일과 웹사이트

지원 이메일로 문의하면 이용자가 보낸 이메일 주소, 본문과 첨부 내용이 문의 확인과 답변을 위해 담당자에게 전달됩니다. 필요한 정보만 보내 주세요. 공개 지원 메일은 Gmail을 사용하며, 메일 서비스의 처리는 Google 개인정보처리방침을 따릅니다.

이 지원 페이지는 이메일 앱을 여는 링크를 제공하며 별도 문의 양식, 로그인, 개발자가 추가한 분석·추적 스크립트나 자체 쿠키를 넣지 않습니다. GitHub Pages로 호스팅될 때 호스팅 제공자는 IP 주소 등 접속 관련 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침에서 확인할 수 있습니다.

5. 보관·삭제 요청과 문의

문의 정보는 답변과 필요한 후속 처리를 위해 사용합니다. 답변과 후속 처리가 종료되고 더 이상 필요하지 않으면 삭제합니다. 법적 의무 이행이나 분쟁 처리에 필요한 자료는 그에 필요한 범위와 기간 동안 보관합니다.
